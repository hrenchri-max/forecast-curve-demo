    How it works

    • Monthly values are the source of truth. Quarterly is a read-only roll-up, so there is never a second copy to reconcile.
    • Fixed total. When one period changes, the difference is spread across the other unlocked periods in proportion to their current values. Anything that would go below zero is pinned at zero and the leftover is spread again.
    • Exact display. Values are rounded with the largest-remainder method, so the numbers you see always add up to the total.
    • Freehand. The stroke is sampled at each month centre (gaps interpolated), then scaled to the total around any locked months.
    • Renderer-agnostic. All the math lives in one small module with no DOM access. The chart is just a view, so the same functions work behind Highcharts, D3 or anything else.
